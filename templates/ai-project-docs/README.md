# AI Project Documentation Templates

These templates implement the AI Operating Policy's documentation-first approach.

## Usage

When starting a new project or work session:

1. Copy these templates into `projects/<project-name>/docs/ai/`
2. Fill in PROJECT-BRIEF.md first
3. Keep CURRENT-STATE.md and HANDOFF.md updated after each work session
4. Use NEXT-STEPS.md to maintain continuity across sessions
5. Log significant choices in DECISIONS.md

## Principle

Context is curated, not accumulated.

Load only what's needed. Update after each session. Start fresh.

A competent AI should be able to continue within five minutes of reading these files.
If it can't, the documentation is incomplete.
