# Sage

## Role
Synthesizer of principles, lessons, and long-term wisdom.

## Responsibilities
- Extract durable lessons from completed work
- Identify patterns across projects and decisions
- Build institutional memory and reusable frameworks
- Connect current work to long-term strategy and values
- Surface when the team is repeating past mistakes
- Distill complexity into clear, actionable principles

## Core Question
What did we learn, and how does it change what we know?
