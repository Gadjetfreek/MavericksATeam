# MavericksATeam

An AI-guided operating system for strategy, execution, research, building, critique, learning, and scenario planning.

## Mission

Turn complex goals into clear decisions, coordinated action, durable systems, and accumulated wisdom.

## The Team

| Agent | Primary Role | Status |
|---|---|---|
| **Chat** | General strategist, facilitator, and decision integrator | 🟢 Active |
| **Jeebs** | Operations manager, project coordinator, and repository steward | 🟢 Active |
| **Sentinel** | Critic who finds flaws, risks, assumptions, and blind spots | 🔲 Next up |
| **Scout** | Researcher and information gatherer | 🔲 Dormant |
| **Forge** | Builder of code, documents, systems, and deliverables | 🔲 Dormant |
| **Sage** | Synthesizer of principles, lessons, and long-term wisdom | 🔲 Dormant |

> Until an agent is energized, Jeebs and Chat cover their duties.

## The Operating Loop

```
JEEBS ──► CHAT ──► SCOUT ──► FORGE ──► SENTINEL ──► SAGE ──► JEEBS ──► ORACLE
  ▲                                                                        │
  └────────────────────────────────────────────────────────────────────────┘
```

Jeebs sits at both the beginning and the end of each cycle: first to organize the work, last to close the loop.

## Repository Map

```
agents/          — Role charters and behavioral instructions
projects/        — Active project workspaces
decisions/       — Decision records
knowledge/       — Durable facts, principles, and reference material
workflows/       — Repeatable operating procedures
templates/       — Reusable project, decision, research, and review templates
inbox/           — New ideas and unsorted requests
archive/         — Completed or inactive work
```

## Start Here

1. Drop a new request in `inbox/`
2. Jeebs triages and creates a project folder
3. Chat writes the project brief and frames the decision
4. Scout researches (when energized)
5. Forge builds (when energized)
6. Sentinel reviews (when energized)
7. Sage records lessons (when energized)
8. Oracle models what happens next (when energized)
9. Jeebs closes the loop

## Working Principle

Every meaningful project should leave behind:

- a clear decision
- an owned next action
- a reusable artifact
- a recorded lesson
- and an improved view of the future
